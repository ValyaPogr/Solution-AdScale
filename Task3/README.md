# Task 3. Данные, масштабирование и отказоустойчивость

## Описание

В рамках задания разработана стратегия хранения и обработки данных для микросервисной архитектуры DSP-платформы. Рассмотрены вопросы выбора баз данных, масштабирования, кэширования, потоковой обработки событий и обеспечения отказоустойчивости.

## Структура проекта

```text
Task3/
├── README.md
├── database-strategy.md
├── scaling.md
├── caching.md
├── event-streaming.md
├── failover.md
└── diagrams/
```

## Состав документации

- **database-strategy.md** — выбор баз данных для каждого сервиса.
- **scaling.md** — репликация, шардирование и CQRS.
- **caching.md** — стратегия кэширования с использованием Redis.
- **event-streaming.md** — потоковая обработка событий с использованием Apache Kafka.
- **failover.md** — стратегия отказоустойчивости, резервного копирования, RPO и RTO.
- **diagrams/** — архитектурные диаграммы хранения данных, масштабирования и потоков данных.
