# AdScale Solution Architecture

Проект демонстрирует разработку целевой архитектуры рекламной RTB-платформы AdScale.

## Содержание

- Анализ текущей архитектуры (AS-IS)
- Архитектурные драйверы
- Целевая архитектура (TO-BE)
- Диаграммы C4 Container
- Architecture Decision Records (ADR)

## Цели проекта

- поддержка 18 000 RPS без деградации SLA;
- достижение P95 ≤ 100 мс;
- подготовка платформы к масштабированию до 50 000 RPS;
- переход от монолитной архитектуры к микросервисной с использованием Strangler Fig Pattern.
