# Task 1. Архитектурная диагностика и целевое видение AdScale

## Описание

В рамках задания выполнен анализ текущей архитектуры платформы **AdScale**, определены архитектурные драйверы, выбрана стратегия эволюции системы и разработана целевая архитектура. Ключевые архитектурные решения оформлены в формате **Architecture Decision Record (ADR)**.

## Структура проекта

```text
Task1/
├── README.md
├── AS-IS.md
├── Drivers.md
├── TO-BE.md
├── Diagrams/
└── adr/
```

## Результат

Предложена стратегия постепенного перехода от монолитной архитектуры к микросервисной с использованием **Strangler Fig Pattern**, внедрением **API Gateway**, **Redis**, **Apache Kafka** и принципа **Database per Service** для повышения производительности, масштабируемости и отказоустойчивости платформы.
