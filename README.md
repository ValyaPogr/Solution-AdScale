# Solution-AdScale

Архитектурный проект, выполненный в рамках курса **«Архитектор решений»**.

Проект посвящён проектированию высоконагруженной рекламной платформы (AdTech) и последовательно охватывает путь от анализа предметной области до построения масштабируемой отказоустойчивой архитектуры.

# Описание заданий

## Task 1 — Анализ предметной области и базовая архитектура

Цель этапа — определить архитектурное видение будущей платформы.

Основные результаты:

* описание бизнес-задачи;
* функциональные требования;
* нефункциональные требования;
* архитектурные драйверы;
* ограничения проекта;
* модель предметной области;
* первоначальная архитектура системы;
* диаграммы взаимодействия компонентов.

---

## Task 2 — Проектирование RTB-платформы

На втором этапе выполняется проектирование высоконагруженной платформы Real-Time Bidding.

Рассматриваются:

* архитектура DSP;
* сервис проведения аукциона;
* взаимодействие компонентов;
* API Gateway;
* обеспечение надёжности;
* обработка ошибок;
* балансировка нагрузки;
* архитектурные решения (ADR).

---

## Task 3 — Масштабирование платформы

Заключительный этап посвящён обеспечению работы системы при очень высокой нагрузке.

Основные темы:

* стратегия хранения данных;
* горизонтальное масштабирование;
* репликация;
* шардинг;
* распределённое кэширование;
* потоковая обработка событий;
* отказоустойчивость;
* Disaster Recovery;
* High Availability.

---

# Архитектурные принципы

При разработке проекта используются современные практики проектирования высоконагруженных распределённых систем:

* Domain-Driven Design (DDD);
* Event-Driven Architecture (EDA);
* Microservice Architecture;
* CQRS (при необходимости);
* API Gateway;
* Database per Service;
* Stateless Services;
* Horizontal Scaling;
* Cache Aside;
* Event Streaming;
* High Availability;
* Failover.

# Основные архитектурные решения

В процессе выполнения проекта принимаются решения относительно:

* декомпозиции системы;
* взаимодействия сервисов;
* хранения данных;
* масштабирования;
* кэширования;
* обработки событий;
* обеспечения отказоустойчивости.

Все значимые решения оформляются в виде ADR.

---

# Цель проекта

Продемонстрировать навыки архитектора решений при проектировании высоконагруженной рекламной платформы:

* анализ требований;
* проектирование архитектуры;
* выбор технологий;
* обоснование архитектурных решений;
* обеспечение масштабируемости;
* обеспечение отказоустойчивости;
* подготовка архитектурной документации.
