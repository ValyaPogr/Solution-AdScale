# Task 2. Проектирование RTB и интеграции с DSP

## Описание

В рамках задания спроектирована архитектура RTB-подсистемы для интеграции AdScale с новой DSP-площадкой. Выполнено выделение сервиса расчёта ставок, определены взаимодействия между сервисами, спроектированы API Gateway и механизмы обеспечения надёжности.
